
  # POS and Inventory Dashboard

  This is a code bundle for POS and Inventory Dashboard. The original project is available at https://www.figma.com/design/x0sL9RMG2sfwpQQZgFsFr8/POS-and-Inventory-Dashboard.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the frontend development server.

  Run `npm run server` to start the backend API server at `http://localhost:4000`.

  Run `npm run dev:full` to start both the frontend and backend together.

  For production deployment:
  1. Run `npm run build` to build the frontend into `dist/`.
  2. Run `npm start` to start the backend and serve the built frontend alongside the API.
